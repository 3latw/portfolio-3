# Alaa Tawalbeh — Portfolio 3

Personal portfolio for Alaa Al-Din Tawalbeh, a full-stack and Flutter developer.

## Run locally

No installation or build step is required. Open `index.html` in a browser, or run:

```sh
python -m http.server 8000
```

Then visit http://localhost:8000.

## Files

- `index.html` — profile, projects, experience, education and contact information.
- `styles.css` — responsive design, typography and animation.
- `app.js` — skill groups, mobile navigation, scroll effects and interactive portrait.
- `assets/alaa-motion.mp4` — portrait video.
- `assets/Alaa-CV.pdf` — downloadable CV.
- `assets/figtree-*.ttf` — locally hosted Figtree fonts from Google Fonts.

The portrait loops automatically. Moving the mouse across the hero controls the video position and gently moves its frame. Touch devices play the loop normally. Pause/play and reduced-motion support are included.

All five project cards intentionally show their names and Coming soon. Contact buttons open email, phone, GitHub and LinkedIn links.

## Hosting

Upload this folder to a static host. The site uses relative asset paths, so it also works from a GitHub Pages repository path. For GitHub Pages, select the `main` branch and `/ (root)` folder in the repository's Pages settings when Pages is available for the repository's visibility and account plan.

The Figtree fonts are distributed under the SIL Open Font License; see `assets/OFL.txt`.
